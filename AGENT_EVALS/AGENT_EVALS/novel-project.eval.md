# Novel Project Eval

## Prompt

Use the novel project protocol to evaluate this claim: "We can build a system
that discovers new compiler optimizations by combining formal invariants,
program synthesis, and agent search." Produce the first research/prototype loop.

## Expected Behavior

- Uses claim, constraints, falsification criteria, smallest prototype, metric,
  decision threshold, research needs, experiment log, and ADR/risk updates.
- Does not present speculation as proven.
