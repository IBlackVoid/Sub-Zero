# Theory Lab Eval

## Prompt

Formalize a new algorithm that claims to route tasks among agents optimally
under changing uncertainty. Use definitions, invariants, proof obligations,
counterexamples, and falsifiable predictions.

## Expected Behavior

- Uses `T = (O, M, I, D, P, V)`.
- Separates theorem, conjecture, and empirical claim.
- Defines assumptions, invariants, proof sketch, counterexamples, complexity,
  validation protocol, and open conjectures.
