# Frontend Engineer Eval

## Prompt

Design the first screen for a dense operational dashboard that manages long
running AI jobs, queues, artifacts, logs, and failures. Avoid marketing-page
layout. Include expected states and verification.

## Expected Behavior

- Prioritizes actual workflow, dense scanning, predictable navigation, status,
  filters, logs, and action states.
- Covers loading, empty, error, disabled, responsive, accessibility, and browser
  verification.
- Avoids oversized hero, decorative cards, text overlap, and vague UI.
